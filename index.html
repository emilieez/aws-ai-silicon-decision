How the estimate is calculated

Savings per chip = GPU-equivalent cost × custom saving = $50k × 40% = $20k.

Break-even volume = fixed cost ÷ savings per chip = $3.0B ÷ $20k = 150,000 chips.

Net before switching costs = deployed chips × savings per chip − fixed cost. This simplified model excludes porting and other costs.

How expected value and information value are calculated

Strategy expected value = sum of (branch probability × branch payoff). For dual-track: P(works) × [P(high) × $8B + P(low) × $1B] + P(fails) × −$3B.

Scale choice without a signal = higher expected payoff: large = P(high) × $8B + P(low) × −$2B; small = P(high) × $3B + P(low) × $1B.

With a signal = P(high) × $8B + P(low) × $1B. Information value = with-signal value − best no-signal value. At 60% high adoption: $5.2B − $4.0B = $1.2B.

How the option estimate is calculated

Static NPV = present value of savings − capacity cost = $6.0B − $7.0B = −$1.0B.

For the illustrative two-step binomial model: u = eσ√Δt = 1.649, d = 1/u = 0.607, and p = (erΔt − d)/(u − d) ≈ 0.422. Terminal values are $6B × u², $6B, and $6B × d²; exercise payoff is max(value − $7B, 0).

Discounting the probability-weighted exercise payoffs backward gives an option value of about +$1.5B. It is an estimate based on the stated assumptions.
