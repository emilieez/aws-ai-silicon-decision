# AWS AI Silicon Decision

An interactive presentation exhibit for the CSCI E-188 case study on AWS's custom AI silicon strategy.

## View locally

Open `index.html` in a browser, or serve this folder with a local static web server.

## Contents

- `index.html` — case narrative and interactive exhibit
- `styles.css` — responsive styling
- `script.js` — calculators and interactive controls
- `webpage-guide.md` — detailed explanations and calculation notes

The economics and decision-tree figures are illustrative assumptions, not AWS-reported costs or forecasts. See the guide for formulas and interpretation.
